## **T1-U1: Digitalización en los Sistemas Productivos**

### Diferencia clave

- **Digitalización**: Cambiar formato físico a digital (ej: factura PDF).  
- **Transformación digital**: Cambiar procesos y forma de trabajar con tecnología.

  ### Ventajas de implantar tecnología

- Mejora procesos, comunicación, toma decisiones, flexibilidad, nuevos roles, coordinación.

  ### Entornos IT y OT

| Tipo | Qué gestiona | Ejemplos |
| :---- | :---- | :---- |
| **IT** (Tecnología Información) | Datos, comunicación | Excel, ERP, CRM, email |
| **OT** (Tecnología Operación) | Procesos físicos, maquinaria | Robots, sensores, PLC, SCADA |

- **Conexión IT-OT** \= integrar oficina con planta (ej: venta → reposición automática).

## **T1-U2: Tecnologías Habilitadoras Digitales (THD)**

### Las 4 revoluciones industriales (fechas clave)

| Revolución | Época | Motor / Eje |
| :---- | :---- | :---- |
| 1ª | 1760-1840 | Máquina de vapor |
| 2ª | 1870-1914 | Electricidad, petróleo, producción en cadena |
| 3ª | 1970 | Electrónica, informática, TIC |
| 4ª | 2011-actual | Industria 4.0, THD |

### Principales THD (memorizar ejemplos)

| Tecnología | Ejemplo |
| :---- | :---- |
| IoT | Reloj inteligente |
| IA | Asistente virtual, recomendaciones |
| Robótica avanzada | Robot con visión artificial |
| Impresión 3D | Prótesis personalizadas |
| Cloud | Google Drive, iCloud |
| Big Data | Análisis de redes sociales |
| Ciberseguridad | Antivirus, encriptación |
| RV/RA | IKEA (muebles en realidad aumentada) |

### THD y sostenibilidad

- Reducen recursos, optimizan energía, minimizan residuos, producción bajo demanda.

## **T2-U3: La Nube**

### Concepto

- Almacenar y usar aplicaciones por Internet sin instalación local.

  ### Funciones clave (10)

- Almacenar, compartir, trabajo colaborativo, copias seguridad, streaming, actualizaciones automáticas, acceso remoto, etc.

  ### Tipos de computación

- **Fog**: Capa intermedia (cámaras tráfico)  
- **Mist**: En el dispositivo (sensor industrial)  
- **Edge**: En dispositivos más grandes (router)  
- **Ventaja común**: Baja latencia, tiempo real.

  ### Niveles de la nube (IaaS, PaaS, SaaS)

| Nivel | Qué ofrece | Ejemplo |
| :---- | :---- | :---- |
| **IaaS** | Infraestructura (servidores, red) | AWS, Azure |
| **PaaS** | Plataforma para desarrollar | Google App Engine |
| **SaaS** | Aplicaciones listas para usar | Gmail, Canva |

## **T3-U4: Herramientas Digitales**

### Videocurrículum

- **Duración**: ≈2 minutos  
- **Estructura**: Presentación → motivación → experiencia → formación → habilidades (≥3) → contacto → despedida.

- Recopilación de trabajos y logros.  
- **Estructura**: Sobre mí → conocimientos → proyectos → CV → contacto.  
- **Herramientas**: Weebly o Canva.

## **T3-U5: Proyecto de Transformación Digital**

### ¿Qué es?

- Plan organizado para usar tecnologías digitales y mejorar procesos, comunicación, decisiones.

  ### 10 apartados del proyecto (estructura examen)

| Apartado | Qué incluye |
| :---- | :---- |
| 1\. Portada | Título, imagen, nombre, curso |
| 2\. Índice | Estructura |
| 3\. Introducción | Contexto, situación actual, motivación |
| 4\. Objetivos estratégicos | Logros concretos (sin tecnologías aún) |
| 5\. Áreas a digitalizar | Nombrar ≥3 (RRHH, ventas, producción...) |
| 6\. Implantación tecnologías | **Más importante**: cómo se digitaliza cada área (IA, IoT, cloud...) |
| 7\. Brechas de seguridad | Riesgos \+ ≥3 medidas (cifrado, copias, contraseñas) |
| 8\. Tratamiento de datos | Cómo se recogen, almacenan, protegen, eliminan |
| 9\. Integración de datos | Cómo se conectan aplicaciones (≥2 integraciones) |
| 10\. Idoneidad RR.HH. | Formación, contratación o reasignación |

  ### Seguridad y datos (tabla clave)

| Concepto | Qué es |
| :---- | :---- |
| Brechas | Puntos débiles (almacenamiento, transmisión, acceso) |
| Amenazas | Hackeos, virus, errores humanos |
| Medidas | Cifrado, copias, contraseñas, control accesos |
| Tipos datos | Personales, financieros, legales |
| Ciclo del dato | Recogida → almacenamiento → protección → acceso → eliminación |

  ### Factor humano (clave del éxito)

- Tecnología no basta → personal **capacitado y motivado** \+ formación continua.
